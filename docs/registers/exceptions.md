# Delivery exceptions

No exceptions have been granted. Known gaps and pending approvals are not exceptions.

An agent cannot grant an exception. Record explicit authorised acceptance and
expiry before relying on one; expired or out-of-scope exceptions remain blockers.
Do not accept serious security risk without the appropriate security role.
